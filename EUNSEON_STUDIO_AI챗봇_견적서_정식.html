프로젝트 개요

01 / OVERVIEW
교육용 자료를 사용자가 질문하고 답변받을 수 있는 웹 기반 챗봇으로 구현합니다. 현재 자료의 정리 수준과 원하는 답변 방식에 따라, 정해진 질문·답변을 연결하는 룰 베이스형과 문서를 검색해 자연어로 답변하는 AI RAG형 중 선택할 수 있습니다.

제안 옵션

02 / OPTIONS
OPTION A · 기본형

룰 베이스형 챗봇

3,000,000원

미리 정의한 질문 또는 메뉴에 따라 정해진 답변을 보여주는 방식입니다.

  • 질문–답변 시나리오 및 분기 구조 구현
  • 버튼·키워드 기반 대화 흐름
  • 기본 반응형 채팅 화면 포함
  • 제공 문구와 자료 기준 데이터 반영
  • 간단한 수정이 가능한 구조로 납품
OPTION B · AI형

AI RAG 챗봇

7,000,000원

교육 자료를 검색한 뒤 AI가 질문 의도를 이해하고 자연어로 답변하는 방식입니다.

  • RAG 구조 및 AI API 개발: 5,000,000원
  • 응답형 채팅 UI 개발: 2,000,000원
  • 문서 검색·근거 기반 답변 처리
  • 대화 맥락을 반영한 후속 질문 대응
  • 오류·예외 응답 및 기본 테스트 포함
ADD-ON

상황 시뮬레이션 기능

A·B 어떤 옵션에도 추가 가능한 교육용 시뮬레이션 모듈입니다.

  • 역할극·대화 시나리오 연습 — 특정 상황과 역할을 부여받아 AI와 실전 대화를 연습하는 모드 (1,400,000원)
  • 모의 상황 대응 훈련 — 상황을 제시한 뒤 학습자가 답변·행동을 선택하는 분기형 훈련 모드 (1,100,000원)
01

역할극·대화 시나리오 연습

특정 직업 상황과 역할을 제시하면 학습자가 AI와 실제 대화를 주고받으며 연습합니다. 대화가 자연스럽게 이어지고, 상황에 맞는 표현과 대응 방식을 반복적으로 익힐 수 있습니다.

02

모의 상황 대응 훈련

주어진 상황 설명을 읽은 뒤 학습자가 적절한 답변이나 행동을 선택하는 분기형 훈련입니다. 선택에 따라 다른 결과와 피드백이 제공되어 판단력과 대처 능력을 기를 수 있습니다.

두 방식의 차이

04 / COMPARISON
구분 룰 베이스형 AI RAG형
답변 방식 정해둔 질문과 답변을 1:1 또는 분기형으로 연결 자유로운 질문을 이해하고 관련 자료를 검색해 답변
적합한 경우 질문 범위가 명확하고 자주 바뀌지 않는 안내·FAQ 교육 자료가 많고 질문 표현과 방식이 다양한 경우
장점 비용이 낮고 답변을 완전히 통제하기 쉬움 자연스러운 대화, 자료 확장성, 다양한 질문 대응
한계 등록하지 않은 표현이나 새로운 질문 대응이 어려움 API 사용료가 발생하며 자료 품질과 운영 기준에 따라 품질 변동
운영 질문·답변 추가 시 시나리오 직접 수정 교육 문서 추가·정리 및 답변 품질 지속 점검
